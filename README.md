# Application Mesures

Application autonome (PWA) : fonctionne hors ligne, données stockées sur l'appareil.

## Publier sur GitHub Pages
1. Créer un dépôt GitHub (ex. `mesures`), y déposer tous les fichiers de ce dossier (Add file > Upload files).
2. Settings > Pages > Source : *Deploy from a branch*, branche `main`, dossier `/ (root)`.
3. Ouvrir `https://<utilisateur>.github.io/mesures/` sur le téléphone, puis *Ajouter à l'écran d'accueil*.

Mise à jour : remplacer `index.html` dans le dépôt (et changer `V` dans `sw.js` pour forcer le rafraîchissement du cache).
